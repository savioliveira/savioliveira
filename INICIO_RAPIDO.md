# ⚡ INÍCIO RÁPIDO - AI AUTOMATION

## 🚀 3 PASSOS PARA COMEÇAR

### 1️⃣ EXTRAIR E ENTRAR NA PASTA
```bash
tar -xzf ai-automation-sistema.tar.gz
cd ai-automation-sistema
```

### 2️⃣ EXECUTAR
```bash
python3 run.py
```

### 3️⃣ ACESSAR
**Interface**: http://localhost:5173

---

## 🎯 PRIMEIRO USO

1. **Criar conta** na tela de login
2. **Configurar IA** (opcional): Menu → Configurações → Chaves de API
3. **Testar chat**: Menu → Chat IA → Digite "Olá"
4. **Explorar**: Dashboard, Automações, Pagamentos, Mensagens

---

## 🔧 SE DER ERRO

### Python não encontrado:
```bash
# Instalar Python 3.8+
# Windows: https://python.org/downloads
# Ubuntu: sudo apt install python3 python3-pip
# Mac: brew install python3
```

### Node.js não encontrado:
```bash
# Instalar Node.js 16+
# https://nodejs.org/downloads
```

### Dependências:
```bash
# Manual
pip3 install -r requirements.txt
cd frontend && npm install
```
