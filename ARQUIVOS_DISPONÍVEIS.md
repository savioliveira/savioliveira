## 🚀 COMO USAR

### 1. BAIXAR
Faça download do arquivo: `ai-automation-sistema-completo.tar.gz`

### 2. EXTRAIR
```bash
# Linux/Mac
tar -xzf ai-automation-sistema-completo.tar.gz

# Windows: Use WinRAR, 7-Zip ou similar
```

### 3. EXECUTAR
```bash
cd ai-automation-sistema
python3 run.py
```

### 4. ACESSAR
**Interface**: http://localhost:5173
